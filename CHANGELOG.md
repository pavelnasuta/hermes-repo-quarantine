# Changelog

All notable changes to this project are documented here.

## 0.2.0 — Multi-agent adapters

- Added one canonical safety contract for Hermes, Claude Code, and Codex.
- Added thin host adapters and a JSON-only sandbox-attestation preflight.
- Added a self-contained Hermes distribution bundle with the same preflight contract.
- Added portable adapter and preflight coverage.

## 0.1.0 — Initial release

- Added the Hermes RepoQuarantine skill for zero-trust handling of unfamiliar repositories.
- Added whole-process isolation, controlled execution, and incident-response guardrails.
- Added offline package validation and scenario coverage.
